# Branching

- Work happens on `development`; `main` is release-only.
- Branch names: `<type>/<kebab-description>` where type ∈
  `feat|fix|docs|refactor|perf|test|build|ci|chore`.
- Branches the orchestrator creates on **target** repos follow
  `ai/<role>/<card-short-id>-<slug>` so PRs and the board stay legible.
